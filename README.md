# ⚡ FF Booster Pro — مسرّع فري فاير الاحترافي

تطبيق أندرويد أصلي (Native) مخصص بالكامل لتسريع لعبة **Free Fire** على هاتف **Realme C25Y (RMX3269)** — معالج Unisoc T610، رام 4GB، أندرويد 11.

## 🛠 التقنيات المستخدمة (Stack)

- **اللغة**: Java (Android Native) — أخف وأسرع خيار لجهاز 4GB رام
- **الواجهة**: XML Layouts بتصميم داكن غيمنغ + دعم كامل للعربية (RTL)
- **الحد الأدنى**: Android 7.0 (API 24) — **الهدف**: Android 14 (API 34)
- **حجم التطبيق**: ~41 KB فقط! (بدون أي مكتبات خارجية ثقيلة)
- **البناء**: aapt2 + javac + d8 + zipalign + apksigner (سلسلة بناء مباشرة — build-tools 35)

## 📦 التثبيت

1. حمّل ملف `FFBoosterPro.apk` من مجلد `build-output/`
2. على هاتفك: فعّل **"التثبيت من مصادر غير معروفة"** من الإعدادات
3. افتح الملف وثبّته
4. اضغط "⚡ تسريع فائق الآن" ثم "🔥 شغّل فري فاير"

## 🔨 إعادة البناء

```bash
./build.sh
```

يتطلب: JDK 17+، Android SDK (build-tools 35, platform 34).
